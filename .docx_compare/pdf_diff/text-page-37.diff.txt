+The biggest design problem was what layers of complexity needed to be exposed. But hiding 
+simulator installation did not remove hardware limitations or OS dependency as with the MJX 
+experiment which could not separate itself from the host GPU drivers through sandboxed 
+execution. Arbitrary Python enables unrestricted state changes which make the runtime 
+unsafe, while a static reward catalogue is safe, but too simple to handle environments where 
+more advanced logic is required. EasyRTG solved this by only exposing those inputs that are 
+used to stimulate learning, observations, actions and termination signals, and the remainder 
+of the logic to be executed by the agent was compiled into a controlled backend.
